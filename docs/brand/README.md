# ScoutLens brand

Created with the built-in image generation tool. The master transparent PNG is
`scoutlens-logo-source.png`; the production header uses
`public/brand/scoutlens-mark.png`. PNG favicon sizes, a multi-size ICO and an
Apple touch icon are derived with Lanczos downsampling, preserving transparency.
The wordmark remains accessible HTML text in the shared `Brand` component.

## Generation prompt

Use case: logo-brand. Asset type: standalone square brand symbol for ScoutLens, an explainable football scouting and player-comparison web app. Design one original polished minimal geometric logo, no lettering: a bold dark forest-green circular scouting lens enclosing a very simplified football motif, with a subtle short angled lens handle integrated elegantly at lower right. Strong silhouette, balanced substantial strokes and clear negative space; should remain instantly legible at 16 to 32 pixels. Use solid forest green #244B3B and restrained sage green #91AA72 accents. Flat vector-like precise clean edges, refined contemporary sports analytics identity, calm and confident. Center the symbol, occupying about 85% of the square canvas. Fully transparent background. No text, no wordmark, no letters, no extra symbols, no mockup, no drop shadows, no gradients, no 3D, no fine outlines or intricate football panels. Deliver a single finished emblem.
